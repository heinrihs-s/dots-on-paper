# Dots on Paper: launch package

Lead with a tiny cute dot calmly delivering **“Your calendar needs a lawyer.”** Then use the **NOO** interruption for a second joke, and the source release for the payoff. The personal dot is **heidot**; the integration is **Dots on Paper**. The visuals are staged output. The software can accept an actual reply through MCP after the dot is connected. A separate Instinct-inspired still is an independent concept, with no Instinct connector.

Use [posts.md](posts.md) for captions, [storyboards.md](storyboards.md) for the cuts, and [media-manifest.json](media-manifest.json) for the media files, dimensions, durations, and checksums. The [reminders GIF](media/dot-reminders.gif) and [NOO GIF](media/dot-noo.gif) are 960 × 720 animations for the GitHub README or a quick preview. They play once and leave the result visible; the MP4s are the primary films.

## Keep the scene believable

The answer should read like a useful assistant result: a compact reminder list, clear timing labels, and one short judgment. “Your calendar needs a lawyer” belongs inside the assistant's reply, alongside the reminders. It should not look like a headline pasted onto an unrelated screenshot. The layout is a reusable reply view, so ordinary answers and other reminder lists should fit without changes to the design.

The second film is a fictional conversation. Its reply says “Okay, understood. Texting your wife about your date with Paula tonight.” The status immediately frames that as **Draft ready · Waiting for approval**. The user's **NOO** is followed by **Cancelled. Nothing sent.** The caption and source provenance identify the scene as staged. The plugin has no texting tool, and OpenAI's dot documentation currently describes native texting as coming soon. The complete factual boundary is in [product-facts.md](../docs/product-facts.md).

The campaign uses lowercase **heidot** as the display name. For a live demonstration, name the source accurately: **ChatGPT dot** means the ongoing ChatGPT agent; **Codex reply** means an answer from a coding task. The four illustrated characters are this project's display artwork. A scripted imitation of either source remains a demo.

## Media use

The master films are 1600 × 1200, H.264, approximately 16 seconds. GIFs are 960 × 720 and play once. Both use snapshots from the bridge's native renderer, with an accelerated half-second thinking cadence. The reminder result is held for ten seconds and the NOO cancellation for seven; no animation restarts after the result. Native 1872 × 1404 screen images offer a closer view of the reply and work well as an additional image post; they are not photographs of a physical TRMNL X. A 4:3 clip can be uploaded directly. The regeneration instructions are in [media/README.md](media/README.md).

Use the staged-demo caption when reposting the dot films. Keep the Instinct concept labels when cropping its image or adding a thumbnail. Use invented names only; the provided names are fictional scenario copy. Generated dot assets and font licensing are documented in [NOTICE.md](../NOTICE.md).

## Instinct is a separate concept

[Instinct](https://instinct.com/) describes a personal assistant that connects apps and devices, uses phone/computer context, and can be contacted by text or call. Its [privacy policy](https://instinct.com/privacy-policy) describes permissions-dependent connected information. Those are Instinct product statements, not capabilities implemented by this bridge.

No public developer API, MCP, webhook, e-ink, or Home Assistant integration documentation was identified in the checked sources. The fourth post is therefore **“What if Instinct had an e-ink screen?”**, with original scripted output, no live connection, and no partnership claim. The image states **INSTINCT-INSPIRED CONCEPT · SCRIPTED OUTPUT**, with an **INSTINCT-INSPIRED CONCEPT / NO CONNECTOR** studio footer. Its artwork is an independent mockup. Do not present a beta account screenshot, private product output, or unsupported connector as part of this package. The actual product's [terms](https://instinct.com/terms) matter before using a live account in public footage.
