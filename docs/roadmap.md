# Beta implementation and remaining gates

The [strategy](strategy.md) is the dated proposal. This record tracks its implementation without replacing the original evidence.

Implemented for `0.2.0b1`: guided start/try/source/display checklist; launcher-assisted one-use local pairing; real-renderer test card; installed and running build fingerprints; separate source/image/BYOS/upload receipts; configurable thinking expiry; a separately retained last completed result; restore, clear-display and clear-history controls; full local text and panel length guidance; battery-friendly still images; durable/coalesced stock webhook delivery with quota and failure recovery; editable browser trial and safe sample export; outcome-focused entry pages; versioned runtime/wheel packaging, checksums, artifact checks and native container CI; hardware issue form, recipes and bounded contributor tasks.

| Gate | Status | Evidence needed |
| --- | --- | --- |
| Source, browser and isolated artifact behavior | Implemented; verification recorded in verification.md | Passing checks for the exact released commit |
| One interactive local assistant configuration | Adapter and configuration provided; reproduction pending | Actual assistant tool call and useful result in the browser, named client/version |
| One observed physical daily-use loop | Pending external observation | Real result, panel model/firmware, settings, latency and restart/disconnect recovery |
| Stock Webhook Image account feasibility | Adapter implemented; account/panel test pending | Accepted PNG and observed panel, account prerequisites and rate-limit recovery |
| Fresh setup by target users | Study prepared; not run | At least 8/10 unaided real browser results within ten minutes; all failures recorded |
| Independent hardware reproduction | Not run | Three owners with exact environments and observed output |
| Seven-day retention | Not run | At least five of ten activated users still using a real recipe on days 5–7 |
| Live HA and HACS installation | Deferred pending runtime | Exact HA/HACS versions, real installation and bridge connection |
| Normal-speed desk film and public launch | Held behind physical and user gates | Observed task/result/return sequence, honest setup claim and permission for shared content |

Use beta engineering downloads for validation. Hardware-led promotion waits for the missing evidence. Do not replace those gates with test counts or GitHub stars. The bounded inbox, additional clients/panels, more characters, cloud hosting and a native app remain deferred until retained users demonstrate need.
